# 北京某普通办公楼项目资料摘要（改善版）

## 1. 项目基本信息

项目位于北京市朝阳区，为新建普通办公楼，总建筑面积约 42000 平方米，当前处于方案深化至初步设计阶段。项目目标为绿色建筑二星级预审，并评估三星级提升路径。

## 2. 已补充资料

当前已经补充：

- 围护结构热工参数表和窗墙比统计
- 照明功率密度计算书
- 建筑能耗模拟结果
- 可再生能源系统专项方案
- 绿色建筑评分计算表
- 正式专项计算报告

建筑能耗模拟报告已经形成可供预审使用的阶段性结果。照明功率密度已经完成分区统计。可再生能源专项方案已经明确屋顶光伏和热泵系统的初步技术路径。

上述资料仅用于方案及初步设计阶段预审，相关参数仍需在施工图阶段更新。

## 3. 尚缺资料

当前仍未提供：

- 采光模拟结果
- 绿色建材比例统计

## 4. 评审边界

本资料不作为最终绿色建筑认证结论。涉及控制项、最终得分、模拟边界条件和申报结论的内容，仍需由专业人员复核。
