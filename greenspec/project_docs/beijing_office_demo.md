# 北京某普通办公楼项目资料摘要

## 1. 项目基本信息

本项目位于北京市朝阳区，建筑类型为普通办公楼，当前处于方案深化至初步设计阶段。项目为新建公共建筑，总建筑面积约 42000 平方米，其中地上建筑面积约 32000 平方米，地下建筑面积约 10000 平方米。

建筑地上 10 层，地下 2 层，建筑高度约 45 米。项目目标为绿色建筑二星级预审，并希望评估三星级提升路径。

## 2. 当前设计资料

当前已提供以下资料：

- 项目参数表
- 建筑设计说明初稿
- 节能专篇初稿
- 绿色建筑策划表

当前尚未提供以下资料：

- 完整围护结构热工参数
- 窗墙比统计表
- 照明功率密度计算
- 建筑能耗模拟结果
- 采光模拟结果
- 可再生能源系统专项方案
- 绿色建材比例统计

## 3. 初步设计策略

建筑方案拟采用高性能外围护结构、节能照明系统、分区控制空调系统和节水器具。设计团队计划在初步设计阶段进一步明确冷热源系统、可再生能源利用方式、照明功率密度和室内环境控制策略。

项目计划控制建筑能耗，并在条件允许时评估屋顶光伏、空气源热泵或其他可再生能源利用方案。但目前尚未形成正式专项计算书。

## 4. 绿色建筑目标

项目当前目标为绿色建筑二星级预审。三星级作为提升目标，需要进一步核查以下内容：

- 是否具备更高性能的节能设计策略
- 是否具备可再生能源利用方案
- 是否具备室内环境专项分析
- 是否具备绿色建材比例统计
- 是否具备运行管理和智慧化系统设计
- 是否完成必要的模拟计算和专项报告

## 5. 人工复核边界

本资料仅用于方案/初设阶段绿色建筑咨询预审，不作为最终绿色建筑评价结论，也不作为施工图审查意见。涉及强制性条文、星级得分、专项计算和申报结论的内容，均需由专业人员人工复核。
